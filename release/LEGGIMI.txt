1. In Steam: tasto destro sul gioco -> Gestisci -> Sfoglia i file locali.
2. Apri la cartella  MadeInAbyss-BSFD\Content\Paks
3. Copia li' il file  MadeInAbyss-BSFD-ITA_99_P.pak  (e' un file in piu', non sostituisce nulla).
4. Gioca con la lingua del testo impostata su INGLESE: la patch sostituisce l'inglese con l'italiano.

Le voci restano originali (giapponese o inglese).
